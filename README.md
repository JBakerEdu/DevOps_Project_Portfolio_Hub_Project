# DevOps Project: Project Portfolio Hub

## Description
The Project Portfolio Hub is a centralized platform designed to help users manage and showcase their projects professionally and organizationally. It includes various features that enhance project visibility, organization, and customization.

##Project Portfolio Hub – Setup Script Instructions

###Requirements

To use the setup script, your system must meet the following requirements:
	- Proper download of the complete project folder and file structure
	- Java 11 or higher
	- Maven installed and configured
	- Bash shell available (e.g., Terminal, Git Bash, or any Unix-like shell)

How to Use the Setup Script
	- Navigate to the project folder where setup.sh is located.
	- You can run the script by opening a shell and executing the following command:
			./setup.sh
	- If your system is configured to support it, you may also double-click the setup.sh file to launch it directly.
	- Once the script is running, follow the output displayed in the terminal. You will be prompted to enter a number between 1 and 5 to choose an action from the menu. Each option corresponds to building the project, running the Java application, starting the website, running tests, or exiting the script.
